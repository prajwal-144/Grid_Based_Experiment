# Operator physics tests

Run these tests before retraining. They isolate PSF resampling, support loss, sparse-matrix normalization, and SIS radial duplication.

## Command

For Euclid-like 0.101 arcsec LR data with a FITS PSF natively sampled at 0.168 arcsec/pixel:

```bash
python operator_physics_tests.py \
  --mapping-dir path/to/matrices_0101 \
  --resolution 0.101 \
  --theta-e 0.75 \
  --psf-path path/to/hsc.fits \
  --psf-source-pixscale-arcsec 0.168 \
  --output-dir operator_tests_0101
```

For 0.168 arcsec LR matrices:

```bash
python operator_physics_tests.py \
```

## Why the FITS PSF kernel grows

The FITS array is sampled at its native detector scale. Convolution is performed on the HR image grid, so the same angular PSF must occupy more pixels when the HR pixels are smaller.

The expected linear resizing factor is

```text
native PSF pixel scale / HR target pixel scale
```

Examples:

- 0.168 / 0.084 = 2
- 0.168 / 0.0505 = 3.3267

A native 41-pixel kernel therefore becomes approximately 81 pixels after a factor-two resize, or approximately 137 pixels after a factor-3.3267 resize. The implementation forces an odd size and interpolation rounding can produce 81 or 135 rather than the exact arithmetic estimate. The angular support is approximately unchanged; only the number of samples changes.

The script reports the raw and resampled shapes, expected scale factor, center-delta flux, edge-delta flux, and whether the kernel is larger than the HR cutout.

## Why zero rows and zero columns can reverse

For a matrix M with shape output-by-input:

- a zero row means an output cell receives no input support;
- a zero column means an input cell contributes to no output cell.

This can reverse even when filenames and high-level notebook purpose appear unchanged if any of the following changed:

- `forward_lensing` versus `backward_lensing`;
- the order of the regular and distorted grids passed into the crop function;
- source/image grid assigned as the first two dimensions of the overlap tensor;
- matrix transposition or flattening convention;
- output-cell versus input-cell area normalization;
- angular field of view, which changes which cells map outside the finite grid.

The current old and new matrices have different hashes and different nonzero support. Therefore they were not generated by numerically identical operators, even if the intended notebook logic was similar.

The script saves row-sum and column-sum maps for each matrix. Inspect whether missing support forms an expected outer boundary. Central, annular, asymmetric, or sector-shaped missing support is a failure.

## Test interpretation and acceptance criteria

### 1. Stagewise constant brightness

A constant source should remain constant after each surface-brightness mapping, away from finite-field boundaries.

Accept when, on the cropped interior:

```text
mean: 0.98 to 1.02 preferred; 0.95 to 1.05 maximum tolerance
std: below 0.02 preferred; below 0.05 maximum tolerance
no annular modulation
```

The most important final-chain criterion is approximately `1 -> 1`. A mean near 0.6 is not acceptable.

### 2. Row-normalized diagnostic

This is a diagnosis, not automatically the final production operator.

If row normalization changes the constant response from nonuniform to nearly one and removes extra Gaussian rings, the current matrices are normalized as input-flux distributors rather than output surface-brightness samplers. Matrix generation should then be corrected using overlap area divided by output-cell area.

### 3. Support maps

Accept when zero support is physically explainable by finite field of view and lies mainly at the outer boundary.

Reject when zero rows or columns form:

- central holes;
- annuli;
- radial spokes;
- asymmetric quadrants;
- disconnected interior regions.

For the backward mapping, all LR pixels containing the observed arcs must contribute to the reconstructed source.

### 4. Independent analytic SIS reference

For a compact centred Gaussian, the analytic inverse-ray-shooting result and sparse result should have the same primary annulus.

Accept when:

```text
primary radial peak error <= 1 HR pixel
no second peak above 10% of the primary unless the analytic reference has it
normalized radial-profile error <= 5%
sparse-vs-analytic image relative MSE <= 0.05 preferred
```

A strong sparse-only peak at radius 18 when the expected Einstein radius is 8.9 or 14.9 is a failure.

### 5. PSF sampling

Accept when:

```text
resampled kernel sum = 1 within 1e-5
center-delta output sum = 1 within 1e-3
reported resizing factor matches native_scale / HR_scale
PSF centroid remains centered within 0.25 output pixel
```

For edge delta tests, flux can be below one under zero padding. Record this loss. If observed arcs approach the boundary, either pad the image before convolution or use a sufficiently cropped PSF and document the discarded encircled energy.

## Final decision rule

The sparse SIS pipeline is ready for training only when all of these are true:

1. constant brightness is preserved;
2. regular-to-log-to-regular mapping does not introduce rings;
3. compact Gaussian sparse SIS matches the analytic SIS reference;
4. support loss is restricted to physically expected boundaries;
5. PSF is correctly resampled and normalized;
6. a `mu_weight=0` baseline produces no duplicated annulus;
7. increasing `mu_weight` changes smoothness but not the inferred Einstein-ring radius or image multiplicity.

After those pass, run a controlled ablation with identical seed, data, matrices, PSF, epochs, and schedule:

```text
mu_weight = 0
mu_weight = 0.001
mu_weight = 0.003
mu_weight = 0.01
```

A correct magnification regularizer may reduce unsupported source curvature. It must not create an additional image ring that is absent in the LR observation and analytic forward model.
